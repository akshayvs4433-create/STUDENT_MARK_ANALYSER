# Student Marks Analyzer

A simple C++ program to analyze student marks using functions and loops.

## Features
- Calculate total marks
- Calculate average marks
- Find highest marks
- Find lowest marks
- Count passed students
- Count failed students

## Pass Mark
40 marks

## Language
C++

## How to Run

Compile:
```bash
g++ code.cpp -o code
```

Run:
```bash
./code
```
